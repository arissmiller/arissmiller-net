# SUBSUNK

SUBSUNK is a code used by the undersea rescue command when they believe a submarine has been sunk. I wanted to design a simple game that used limited visibility and movement to create a suspensful, enemy-wave-survival experience. The submarine can only follow a few courses, and can't move very fast. Enemies are invisible until scanned by the radar beam.

## Project Objectives
 - Create a suspensful game that is engaging enough to play a few rounds
 - Use limited visibility and movement to create challenge

## Challenges
- Enemy spawning and AI
- Balancing limited visibility and movement with fairness
