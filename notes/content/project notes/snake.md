# Snake

I always enjoyed playing Snake game during classes. This project was one that I hand-coded a few years ago for the first version of my personal web site, plus a little added flair from AI-Generated code.

## Project Objectives
    - Create the best snake game on the internet
    - Simple gameplay, selective difficulty, retro vibe, a little flair but still minimalist.
