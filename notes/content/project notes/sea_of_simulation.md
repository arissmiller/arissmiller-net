# Sea of Simulation

The 'Sea of Simulation' is a feature of The Grid from the movie Tron: Legacy. I've been using TRON-inspired names since the premise of TRON: Legacy is a programmer creating a digital world by interacting with computer programs that can talk and reason like human characters. The process of designing this project using an AI agent resembles this concept, and the bright neon lights against an emtpy vaccum resembled the TRON world.

## Project Objectives
    - Create aesthetically pleasing noise that can be generated and random or customized based on parameters
    - Inspired by corporate website backgrounds and similar abstract art
    - Create something that is entertaining enough to hit 'Randomize' a few times

## Challenges
    - Surpisingly, this wasn't very hard and everything went pretty smoothly
