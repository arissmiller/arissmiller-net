# Orbital Combat Prototype

This is a prototype of a multiplayer game that uses orbital physics to create tactical combat scenarios. I mostly enjoyed designing the physics engine and game mechanics, I have been stalling on the actual game design aspect, but I plan to revisit it soon. The vision is combat that doesn't rely on aim, but timing, tactics, deception and strategy. The weapons and combat style is inspired by 'Star Trek - The Next Generation' 

## Project Goals:
 - Build an engaging and fun spaceflight scenario that uses orbital physics as part of the game
 - Create a combat system that relies more on tactics then aim and reaction time
 - Create a cross-platform game using web technologies

## Challenges:
 - Choosing when to be physics-accurate and when to take 'shortcuts'
 - Desiging and balancing weapon systems
 - Optimizing the calculations needed for gravity and missile guidance systems
 - Getting accurate 'forecast lines' for ship trajectory that weren't bouncing all over the place
