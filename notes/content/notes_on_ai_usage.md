# Notes on AI Usage

This site and these prototypes were created with ChatGPT codex. This was my first time experimenting with AI Coding tools and it was really exciting. After spending some time creating software with these tools, I've found they are very valuable for prototyping, but it is very easy to get over your head especially when designing complex systems that are outside of your knowledge. The code it generates is not always the best, but it works well enough for a prototype. I've felt liberated by the ability to create a working prototype of an idea that I have in my mind without deciding wether or not I want to spend weeks or months of research and programming work just to get a basic functioning prototype. That being said, the code it generates is not always the best, and there are definitely things under the hood that I don't understand. However, I was extremely intentional with designing the architecture of these projects and did my best to apply good software design principles and testing. As I expand on these projects more, I expect to spend more time manually refining the genereated output.
